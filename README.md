# Invitación de 15 · Jazmín

Invitación web adaptable a celulares para la celebración del sábado 2 de enero de 2027 en Amelia Eventos, Vedia.

## Publicar con GitHub Pages

1. En el repositorio, abrí **Settings → Pages**.
2. En **Build and deployment**, elegí **Deploy from a branch**.
3. Seleccioná la rama `main` y la carpeta `/ (root)`, y guardá.
4. Cuando termine la publicación, GitHub Pages mostrará el enlace público de la invitación.

Las fotografías se cargan desde Unsplash y las tipografías desde Google Fonts, así que requieren conexión a internet. Para reemplazar las fotos, editá las URL de imagen en `index.html`.
